# Amaysim Shopping Cart

Implementation of the Amaysim shopping cart exercise.

## Requirements

- Node.js 16 or newer

## Install

```bash
npm install
```

This installs Jest (for testing).

## Run the tests

```bash
npm test
```

Runs all 5 tests: the 4 scenarios from the brief plus an empty-cart sanity check.

## Run the demo

```bash
npm run demo
```

Prints the 4 scenarios with their items and totals.
